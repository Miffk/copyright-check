# Проверка авторских прав

Программа для Windows, которая перед загрузкой на YouTube, VK, Twitch или стриминги проверяет трек или готовое видео: нет ли в нём чужой записанной музыки, на которую может прийти заявка Content ID.

Файл прослушивается по фрагментам по 12 секунд, и каждый фрагмент сравнивается с базой Shazam. В ней десятки миллионов записей. На выходе вы получаете:

- цветную полосу по всей длине файла: красным отмечены места, где звучит чужая музыка;
- исполнителя, название, альбом, лейбл, год и ISRC найденного трека;
- точное время, где этот трек звучит в вашем файле;
- отчёт в .txt, если нужно сохранить результат.

Принимаются аудио (mp3, wav, flac, ogg, m4a…) и видео (mp4, mov, mkv, webm…). Можно перетащить в окно сразу несколько файлов или целую папку.

## Скачать

Готовый **CopyrightCheck.exe** лежит в разделе [Releases](https://github.com/Miffk/copyright-check/releases/latest). Скачайте его и запустите двойным щелчком, Python не нужен. Windows может предупредить о неизвестном издателе: нажмите «Подробнее», затем «Выполнить в любом случае».

## Запуск из исходников


1. Установите Python 3.11 или новее с <https://www.python.org/downloads/>. При установке **отметьте галочку «Add python.exe to PATH»**.
2. Скопируйте папку с программой на компьютер.
3. Запустите двойным щелчком **`Запустить.bat`**. Первый запуск займёт 1–3 минуты: программа сама скачает нужные компоненты. Следующие запуски будут быстрыми.

### Собрать .exe самому

Если хотите отдельный файл, который работает на любом компьютере без Python: после первого запуска откройте **`Собрать exe.bat`**. Через пару минут появится `dist\CopyrightCheck.exe` размером 100–200 МБ (внутри Qt и ffmpeg). Его можно копировать и запускать где угодно, а ещё перетаскивать файлы прямо на его значок.

## Сколько это занимает

Shazam бесплатно принимает около трёх запросов в минуту. Программа сама держит этот темп, а в окне видно, сколько осталось ждать. Ориентиры для трека на 3 минуты:

- **Тщательная проверка** слушает весь файл без пропусков: 15 фрагментов, около 4–5 минут.
- **Быстрая проверка** берёт 12 секунд из каждых 30: 6 фрагментов, около 1 минуты. Подходит для длинных видео, где музыка играет фоном.

Найденные треки появляются на полосе сразу, до окончания проверки.

## Важно понимать

- **Совпадение ≠ нарушение.** Если у вас есть лицензия (купили трек, взяли со стока, музыка из фонотеки YouTube), совпадение не нарушает права. Но автоматическая система всё равно может поставить заявку, и её придётся оспаривать. Сохраните отчёт и лицензию.
- **«Совпадений нет» — не гарантия.** Свежих релизов, малоизвестных авторов и продакшн-библиотек может не быть в базе Shazam, но быть в базе Content ID.
- **Каверы и живое исполнение** чужих песен программа обычно не узнаёт. Она ищет конкретные записи, а права на саму песню (мелодию и текст) у автора всё равно остаются.
- **Слабое совпадение** (трек нашёлся только в одном фрагменте) иногда бывает ложным. Послушайте этот участок сами.
- Программа пользуется неофициальным доступом к Shazam через библиотеку [shazamio](https://github.com/shazamio/ShazamIO). Если Shazam что-то поменяет у себя, может понадобиться обновить библиотеку: удалите папку `.venv` и запустите `Запустить.bat` заново.

## Файлы

| Файл | Что это |
|---|---|
| `app.py` | окно программы |
| `checker.py` | распознавание: разбивка на фрагменты, запросы к Shazam, отчёт |
| `requirements.txt` | список библиотек |
| `Запустить.bat` | установка при первом запуске и запуск |
| `Собрать exe.bat` | сборка одного .exe |

Без окна проверку можно запустить и из командной строки: `python checker.py файл.mp3 fast`.
